# Если игроки не могут подключиться

Memomarium рассчитан на игру по локальной сети. По умолчанию сервер слушает TCP-порт `8080`. Компьютер с запущенной игрой — хост; телефоны и другие компьютеры подключаются к нему по адресу из QR-кода в панели ведущего.

## Сначала проверьте адрес и сеть

1. Откройте панель ведущего на компьютере-хосте и запустите комнату.
2. Покажите игрокам QR-код или ссылку из блока «QR для игроков». Если вводите адрес вручную, используйте LAN-адрес хоста, например `http://192.168.1.25:8080/play/ABCD`.
3. Убедитесь, что хост и устройства игроков подключены к одной локальной сети. Адрес `localhost` работает только на самом компьютере-хосте.
4. Если хост подключился к другой Wi-Fi сети или перезапустил роутер, его LAN-адрес мог измениться. Возьмите актуальную ссылку из панели ведущего.

## Windows спросила о доступе к сети

При первом запуске Windows может показать запрос брандмауэра. Разрешите доступ для Memomarium в **частных сетях**. Не требуется отключать брандмауэр целиком.

Если запрос уже закрыли:

1. Откройте меню «Пуск» и найдите **«Разрешение взаимодействия с приложением через брандмауэр Защитника Windows»**.
2. Нажмите «Изменить параметры», найдите Memomarium и разрешите его для **частных сетей**.
3. Если приложения в списке нет, создайте входящее правило для TCP-порта `8080` только для частного профиля Windows.

В общедоступной или недоверенной сети не включайте разрешение для общедоступного профиля.

## Все подключены к одной Wi-Fi сети, но страница не открывается

- Проверьте, что сервер Memomarium всё ещё запущен на хосте.
- На хосте проверьте, что сеть отмечена Windows как частная, и что брандмауэр разрешает Memomarium или TCP-порт `8080` для частной сети.
- В некоторых гостевых, публичных и офисных Wi-Fi сетях включена изоляция клиентов: устройства имеют доступ в интернет, но не могут соединяться друг с другом. Попробуйте обычную домашнюю сеть или точку доступа без изоляции.
- Для диагностики с устройства Windows в той же сети откройте PowerShell и выполните:
  `Test-NetConnection 192.168.1.25 -Port 8080`
  заменив IP на адрес хоста из QR-ссылки. Значение `TcpTestSucceeded : True` означает, что TCP-подключение к порту доступно.

## Хост и игроки в разных Wi-Fi сетях

LAN-ссылка доступна только устройствам, которым сеть разрешает связаться с компьютером-хостом. Обычная смена Wi-Fi-сети не соединяет две сети между собой. Для игры в разных сетях нужен VPN, который объединяет устройства в одну виртуальную сеть, либо отдельное размещение сервера с настроенной сетевой доступностью. Переадресация порта на роутере сама по себе не является настройкой VPN и может открыть локальный сервер для посторонних.
